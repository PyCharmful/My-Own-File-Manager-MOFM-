# About program
Console version of my file manager.
<br>
A **file manager** that displays the files and folders of a single directory in separate windows.

## Used technologies
- C#

## How to use
Currently, just move to the *bin\Debug\net10.0-windows* and run ***FileManager.exe***.<br>
Just type some commands to do anything.

<details><summary><b>Some commands</b></summary>
  help - message box with all commands<br>
  cd - change directory<br>
  clear - clear the window<br>
  showlast - show last directory<br>
  showfiles - shows only files<br>
  showfolders - shows only folders<br>
  showall - shows files and folders<br>
</details>
