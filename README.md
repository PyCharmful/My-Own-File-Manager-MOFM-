# About program
A GUI version of main (console) program. Update will coming soon.
<br>
A **file manager** that displays the files and folders of a single directory in separate windows.

## Used technologies
- C#
- Windows Forms

## How to use
Currently, just move to the *bin\Release\net10.0-windows* and run ***GraphicOFM.exe***.<br>
In the text box write the path directory and tap Enter to move in it.
